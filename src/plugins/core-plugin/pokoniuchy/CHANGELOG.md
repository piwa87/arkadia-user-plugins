# Changelog

Historia zmian samodzielnego pluginu Pokoniuchy. Przy wydaniu workflow publikuje
w katalogu zawartosc sekcji odpowiadajacej wersji taga.

## [Unreleased]

## [1.1.2] - 2026-09-26

- Dodano konkretnego pokoniucha `Dluga grozna bestia`.
- Dodano komende `poko_dodaj <opis>` do recznego zapisywania dowolnego wpisu w biezacej lokacji.

## [1.1.1] - 2026-09-26

- Dodano wykrywanie harpii opisanych dowolnymi dwoma przymiotnikami.
- Dodano obsluge wielu harpii wymienionych w jednej linii.

## [1.1.0] - 2026-09-25

- Dodano komende `poko_zglos` z odnosnikami do zglaszania bledow i pomyslow.
- Dodano formularze zgloszen GitHub przygotowane dla Pokoniuchow.

## [1.0.3] - 2026-09-25

- Wiadomosci o osobistej kolczastej mlodej wiwernie nie sa juz zapisywane jako znaleziska.
- Zmieniono wyswietlana nazwe na `Pokoniuchy Plugin`.

## [1.0.2] - 2026-09-25

- Dodano ostrzezenie, gdy od zapisania znalezisk swiat zdazyl sie odrodzic.

## [1.0.1] - 2026-09-25

- Uogolniono rozpoznawanie wiwern, smokow, wipperow, endriag, oszluzgow i widlogonow.
- Dodano automatyczna publikacje pluginu do katalogu.

## [1.0.0] - 2026-09-24

- Pierwsze wydanie samodzielnego pluginu Pokoniuchy.
